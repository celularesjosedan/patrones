# 🔐 Control de Patrones de Desbloqueo (Gráfico) · Neon Dark

Herramienta interactiva con **representación gráfica** de los patrones de desbloqueo (Android) más comunes.  
Muestra el dibujo exacto del patrón sobre una cuadrícula 3x3, igual que en la pantalla del celular.

## 🚀 Características

- **50 patrones cortos** (4 puntos) y **50 patrones largos** (7-9 puntos) más usados.
- **Visualización gráfica** de cada patrón (puntos y líneas) en canvas.
- **Probabilidad de éxito** calculada por ranking de frecuencia.
- **Marcado** de patrones probados (tachado + check verde neón).
- **Estadísticas** en tiempo real (pendientes, probados, total).
- **Persistencia local** (guardado automático).
- **Diseño oscuro con neón** (sin animaciones, máxima velocidad).

## 📦 Uso

1. Abre `index.html` en cualquier navegador.
2. Haz clic en un patrón para marcarlo como probado (o desmarcarlo).
3. Los datos se guardan solos.
4. Usa el botón **Reiniciar todo** para resetear.

## 📊 Probabilidad

Basada en la frecuencia relativa de cada patrón en estudios de seguridad (filtraciones reales de Android).

## 🛠 Tecnologías

- HTML5, CSS3, JavaScript (Canvas API)
- localStorage

## 📁 Estructura

- `index.html` — todo en uno.
